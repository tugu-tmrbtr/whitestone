# omarchy-theme-whitestone

A custom [Omarchy](https://omarchy.org) theme styled after whitestone theme.

## Install

```sh
git clone <this-repo> ~/.config/omarchy/themes/whitestone
omarchy-theme-set whitestone
```

## Contents

- `colors.toml` — theme colors
- `neovim.lua`, `vscode.json` — editor color scheme wiring
- `icons.theme` — icon theme reference
- `backgrounds/` — wallpapers
- `preview.png` — symlink to the theme preview background
